PROJECT 04 / MACHINE LEARNING

Spot cancellation risk before the guest arrives.

The problem

Canceled bookings complicate occupancy, staffing, and revenue planning. This project compares interpretable models for identifying cancellation risk before arrival.

Recovered course approach

The original notebook defines a depth-limited decision tree, a pre-pruning search, KNN, and logistic regression, with encoding, scaling, confusion matrices, accuracy, precision, recall and F1. It uses an 80/20 stratified split. Its conclusion names a pruned tree as the preferred model, but the recovered notebook has no saved numeric outputs. This package does not assign that conclusion a fabricated accuracy score.

Portfolio reconstruction

The new demo keeps the three-model comparison and uses a preprocessing pipeline inside cross-validation. Model selection uses training-fold scores only. The test set is used once for final comparison. Inputs are restricted to a small set of assumed booking-time fields; booking changes and cancellation-status fields are excluded.

Default inputs are 1,200 newly generated fictional bookings. Their results demonstrate the workflow only and are not the original course performance. See model_metrics.csv (available on request), confusion_matrices.png, and metadata.json (available on request).

Decision interpretation

Recall measures how many cancellations are identified; precision measures how many flagged bookings actually cancel. A business should choose a threshold using the cost of false alarms versus missed cancellations, then validate on later bookings. The demo uses the default threshold and makes no revenue-savings claim.

Limitations

Synthetic data is deliberately simplified. Random splits do not test future drift, repeated-guest leakage, seasonality changes or hotel-to-hotel transfer. The original missing-value rule dropped columns with over 500 missing observations; this reconstruction instead imputes within training folds and documents that change. No production deployment is claimed.

Evidence: recovered Irakoze_Christa_hw4.ipynb, April 23, 2026. Author: Christa Irakoze. Newly written runnable code and synthetic results are clearly separated from this source.

Portfolio card

Compared decision-tree, KNN, and logistic-regression approaches for hotel cancellation risk. Built reproducible preprocessing and training-only hyperparameter selection, evaluated precision/recall tradeoffs, and explained the need for booking-time feature availability and future-period validation.
