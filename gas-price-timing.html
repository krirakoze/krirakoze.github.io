PROJECT 05 / MACHINE LEARNING

A forecast is only useful if it helps a decision.

Turn a weekly price forecast into cautious buy-or-wait guidance, with a persistence baseline and a low-tank override.

CIS 508 · Spring 2026Team concept + synthetic offline prototype
View code & evidence ↗

Team concept · CIS 508: Machine Learning in Business · Spring 2026 Recovered presentation credits John Wheeler, Marcus Holder, Hrijoo Bosu Mullick, Ryan Wolff, Cameron Anthony, and Christa Irakoze. Christa is assigned the business-value and risk slide.

The problem

A price forecast needs a decision rule before it helps a driver. Filling a nearly empty tank can be necessary even if a model predicts a lower price later. Uncertain forecasts should not imply certainty.

Historical concept versus this demo

The recovered slides propose multiple models, an accuracy-weighted ensemble, a plain-English explanation and personalized buy/wait guidance. They provide no held-out evaluation or verified savings. Their $50–150 annual saving statement is a proposed benefit, not measured impact, and is not adopted as a result here. The domain printed in the slides is a project concept; this package does not verify a live deployed product.

This newly built offline prototype uses synthetic weekly prices, lag features, a chronological train/test split, a random forest, a ridge regression, and an equal-weight ensemble. A persistence baseline checks whether forecasting adds value. It does not reproduce an unprovided final team model or call the EIA API.

Decision rule

The illustrative decision compares next-week predicted price with the currently observed price. A fixed $0.03-per-gallon threshold creates an uncertainty zone; it is a demo assumption, not a statistically calibrated interval. If the driver's stated tank fraction is at or below 15%, the demo gives a fuel-availability override rather than suggesting delay.

Validation and limits

All lag features are shifted so they use only past observations. The last chronological block is held out. Results are MAE in USD per gallon on fictional data. Equal weights are fixed in advance; test results do not determine ensemble weights. A simulated weekly benchmark cannot validate daily station-level advice, real savings, or local prices.

Evidence: ShouldIBuyGasToday_Presentation.pptx, April 16, 2026. Team contribution and concept are sourced; code, fictional dataset, and benchmark are newly reconstructed portfolio additions.

Portfolio card

Contributed business-value and risk analysis to a team gas-purchase timing concept. Extended it with an offline demonstration that compares an ensemble with a persistence baseline and translates uncertain forecasts into cautious buy/wait guidance using explicit assumptions.
